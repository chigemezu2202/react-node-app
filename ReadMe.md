## ⚙️ Features

### 🔧 Backend
- User Signup
- Email Verification System
- Login / Logout
- Forgot Password
- Reset Password
- Auth Check Middleware
- Welcome Email Template

### 🌐 Frontend
- Modern UI (Tailwind + Framer Motion)
- Signup Page
- Login Page
- Email Verification Page
- Protected Routes
- Dashboard Page

---

## 🔐 Authentication Flow

1. User signs up
2. Verification email is sent
3. User verifies account
4. User logs in
5. Access dashboard
6. Password reset if needed

---

## 🛠️ Tech Stack

### Frontend
- React (JavaScript)
- Tailwind CSS
- Framer Motion
- Zustand

### Backend
- Node.js
- Express
- MongoDB
